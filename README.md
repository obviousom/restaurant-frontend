# RestaurantMate — Frontend

React + Vite + TypeScript client for RestaurantMate.

## Stack
- React 19 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- TanStack Query + Axios (server-state/API layer)
- React Router
- React Hook Form + Zod
- Recharts (dashboard)

## Layout
See `src/*/README.md` for what each folder owns:
`components/`, `pages/`, `routes/`, `hooks/`, `services/`, `store/`,
`lib/`, `types/`.
